# Product List Manager
Simple console application for maintaining a product lis.

When started it will display the available options as a list:

<img width="507" height="262" alt="image" src="https://github.com/user-attachments/assets/a32518db-fc60-4f3f-b3a9-e345139de2de" />

## Menu options:
1. Add Product: Products can be added in the format CHARACTERS-NUMBER (the input will be converted to upper case). Type "exit" to stop adding products.
2. View Products: Lists all products in alphabetical order.
3. Search Product: Lists all products in alphabetical order where the start of the name matches the search string.
4. Delete Product: Delete a product from the list.
5. Statistics: Shows statistics related to the product list.
6. Exit: Saves the product list and exits the application.
